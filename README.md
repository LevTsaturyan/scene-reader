# scene-reader

Учебный проект: ассистент для слабовидящих. По фото читает вслух текст или описывает сцену, переводит результат на русский или английский и озвучивает.

Это исследование локального пайплайна, а не замена Seeing AI или Google Lookout. Качество чтения вывесок пока низкое, замеры ниже.

## Как это работает

```
фото → EasyOCR
         ├── текст есть → берём текст
         └── текста нет → BLIP описывает сцену (англ.)
       → перевод MarianMT (ru ↔ en)
       → озвучка gTTS: отдельные mp3 для перевода и оригинала
```

OCR, BLIP и перевод работают локально, на GPU, если он есть. Озвучка идёт через gTTS, то есть через Google, поэтому для неё нужен интернет.

## Установка

Нужен Python 3.12. Команды для Windows с NVIDIA GPU:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements-dev.txt
pip install --no-deps gTTS==2.5.4
```

Индекс `cu128` нужен для RTX 5060 Ti: сборка `2.6.0+cu124` на ней падает с `no kernel image is available`.

gTTS ставится отдельным шагом из-за конфликта версий `click` с `huggingface_hub`. На работу озвучки это не влияет.

Tesseract нужен, только если выбрать его как движок или запускать `evaluate_ocr.py`. Нужны языки `eng` и `rus`.

При первом запуске скачиваются модели BLIP, MarianMT и EasyOCR.

## Запуск

Командная строка:

```bash
python -m scene_reader фото.jpg --mode auto --lang ru --out out
```

Режимы: `auto` (OCR, а если текста нет, то BLIP), `text` (только OCR), `scene` (только BLIP).

Веб-интерфейс:

```bash
python app.py
```

Если система работает через прокси и Gradio падает при старте с `WinError 10054`, задайте `NO_PROXY=localhost,127.0.0.1,::1`.

Настройки задаются переменными окружения: `SCENE_READER_TARGET_LANG`, `SCENE_READER_OCR_ENGINE` (`easyocr` или `tesseract`), `SCENE_READER_OCR_LANGS`, `SCENE_READER_OCR_MIN_CONFIDENCE`, `SCENE_READER_MIN_WORDS`.

Тесты не грузят модели и не ходят в сеть:

```bash
python -m pytest -v
```

## Замеры OCR

Набор: 18 фото, в основном вывески, из них на 16 есть текст. 14 снимков сделаны телефоном с монитора со Street View, поэтому на них есть муар, а местами и адресная строка браузера. Такие условия хуже обычной съёмки, а сам набор мал, поэтому цифры показывают сравнение моделей, но не ожидаемое качество в реальной работе. Фото нельзя публиковать, в репозитории их нет.

Эталон — заметные надписи, размечены по фото вручную, без вывода OCR. Регистр не учитывается. CER может быть больше 1, когда лишнего распознано больше, чем есть в эталоне. Порядок надписей на вывесках не определён, а CER и WER его учитывают, поэтому добавлены полнота и точность по словам без учёта порядка.

| Движок | CER | WER | Полнота слов | Точность слов | сек/фото |
|---|---|---|---|---|---|
| Tesseract без обработки | 1.042 | 0.949 | 0.091 | 0.250 | 0.30 |
| Tesseract, серый + автоконтраст | 1.135 | 1.313 | 0.061 | 0.073 | 0.23 |
| EasyOCR, уверенность ≥ 0.5 | 0.832 | 0.960 | 0.121 | 0.245 | 0.19 |

Время для RTX 5060 Ti: Tesseract считает на CPU, EasyOCR на GPU.

Выбран EasyOCR с порогом 0.5: у него самый низкий CER и больше найденных слов. Но точных слов всё равно мало: на этом наборе он находит примерно 12% слов эталона. Предобработка Tesseract здесь ухудшила результат.

Порог числа слов для перехода от OCR к BLIP (EasyOCR, уверенность ≥ 0.5):

| `min_words` | Верный выбор | Пропущен текст | Ложный текст |
|---|---|---|---|
| 1 | 12/18 | 6 | 0 |
| 2 | 9/18 | 9 | 0 |
| 3 | 7/18 | 11 | 0 |
| 5 | 6/18 | 12 | 0 |

Выбран порог 1: на вывесках часто одно слово. Фото без текста в наборе всего два, поэтому столбец «Ложный текст» проверен слабо.

Повторить замер на своих фото: положить в `eval_photos` файлы `.jpg` и `.txt` с тем же именем (для фото без текста `.txt` пустой) и запустить `python evaluate_ocr.py --details`.

## Ограничения

- Распознанный текст часто искажён, и озвучивается он таким же: например, `дokiор` вместо «доктор».
- MarianMT ошибается на коротких фразах без контекста: «Выход» → «Withdrawal», «a red brick wall» → «красную кирпичную стену».
- Строка длиннее 512 токенов без точек и переносов обрезается.
- Язык определяется только как русский или английский.
- Озвучка не работает без интернета, а gTTS использует неофициальный доступ к Google.
- С настоящими слабовидящими пользователями проект не проверялся.
- Поворот по EXIF на фото с телефона не проверен.

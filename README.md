# Scene Reader

Помощник для слабовидящих: наводишь телефон на вывеску, этикетку или упаковку, и программа читает текст вслух, а если текста нет, описывает, что на фото. Результат можно сразу перевести на русский или английский.

Всё, кроме озвучки через gTTS, работает локально. С голосом Piper приложение работает полностью без интернета.

## Как пользоваться

Веб-интерфейс:

```bash
python app.py
```

Загрузи фото или сними его с веб-камеры, выбери режим и язык. Приложение покажет распознанный текст, перевод и даст два аудио: перевод и оригинал.

Из командной строки:

```bash
python -m scene_reader фото.jpg --mode auto --lang ru --out out
```

Режимы: `auto` — прочитать текст, а если его нет, описать сцену; `text` — только текст; `scene` — только описание.

## Что внутри

```
фото → поворот по EXIF
     → EasyOCR
         ├── нашлось хотя бы одно слово → читаем текст
         └── текста нет → BLIP описывает сцену (по-английски)
     → перевод MarianMT (ru ↔ en)
     → озвучка: Piper (локально) или gTTS (через интернет)
```

Если озвучка не удалась, например нет интернета для gTTS, текст всё равно показывается. Фото с телефона поворачиваются по метке ориентации, иначе OCR видел бы текст боком.

## Насколько хорошо читает

Для проверки я снял телефоном 50 фото: в основном вывески магазинов, плюс упаковки, указатели и объявления, на русском и английском. 8 фото без текста. Текст на каждом фото я выписал вручную, не глядя в результат OCR.

- **dev** — 20 фото, на них выбирались движок и настройки;
- **test** — 30 фото, на них итоговые цифры.

Набор открыт и лежит в [`eval_photos`](eval_photos). Из фото удалены метаданные, в том числе геолокация, и они уменьшены до 2048 пикселей ([`prepare_photos.py`](prepare_photos.py)). Большинство снимков прошли через Telegram и сжаты примерно до 1280 пикселей.

**Чтение текста на test** (25 фото с текстом):

| Движок | Найдено слов из эталона | Лишних слов среди распознанных | Время на фото |
|---|---|---|---|
| Tesseract | 0–1% | — | 0.2 с |
| **EasyOCR, уверенность ≥ 0.5** | **39%** | 72% | 0.2 с |

**Есть ли на фото текст** (все 30 фото test): EasyOCR решает правильно для 25 из 30 — пропустил текст на 5 фото и ни разу не придумал текст там, где его нет. Tesseract правильно решает только для 8.

Как это выглядит на практике (dev):

| На фото | EasyOCR прочитал |
|---|---|
| цветы подарки подари ей цветы | цветы подарки поаари ей шветы |
| магнит косметик | магнит косметик |
| банкет холл | б анкет холл |
| дворец бракосочетания | ворещ |

**Что я выяснил:**

- Tesseract, классический OCR для сканов документов, на уличных вывесках практически ничего не видит. Нейросетевой EasyOCR — единственный рабочий вариант из двух.
- Увеличение изображения перед распознаванием (×1.5, ×2) не помогло ни на dev, ни на test, а ×2 работает в 10–15 раз медленнее. Поэтому оно выключено.
- Порог уверенности 0.5 — компромисс. При 0.3 находится чуть больше слов (42% на test), но заметно больше мусора, при 0.7 — наоборот.
- На dev EasyOCR нашёл 53% слов, на test только 39%. Наборы маленькие, а на test больше вывесок с декоративными шрифтами. Реальное качество, скорее всего, где-то между.

Полные таблицы и повтор замера:

```bash
python evaluate_ocr.py --split dev --details
python evaluate_ocr.py --split test
```

## Установка

Нужен Python 3.12. Команды для Windows с видеокартой NVIDIA:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements-dev.txt
pip install --no-deps gTTS==2.5.4
```

- Индекс `cu128` нужен для RTX 50-й серии: сборка `2.6.0+cu124` на ней падает с `no kernel image is available`.
- gTTS ставится отдельно из-за конфликта версий `click` с `huggingface_hub`, на озвучку это не влияет.
- Tesseract нужен только для `evaluate_ocr.py`, с языками `eng` и `rus`.
- При первом запуске скачиваются BLIP, MarianMT и EasyOCR.

Голос без интернета:

```bash
python -m piper.download_voices ru_RU-irina-medium en_US-lessac-medium --download-dir models/piper
set SCENE_READER_TTS_ENGINE=piper
```

Если Gradio падает при старте с `WinError 10054` или ошибкой 502, системный прокси перехватывает локальные адреса: задай `NO_PROXY=localhost,127.0.0.1,::1`.

Настройки задаются переменными окружения: `SCENE_READER_TARGET_LANG`, `SCENE_READER_OCR_ENGINE` (`easyocr` или `tesseract`), `SCENE_READER_OCR_MIN_CONFIDENCE`, `SCENE_READER_OCR_MAG_RATIO`, `SCENE_READER_MIN_WORDS`, `SCENE_READER_TTS_ENGINE` (`gtts` или `piper`).

Тесты не загружают модели и не ходят в сеть, они же запускаются в GitHub Actions:

```bash
python -m pytest -v
```

## Что пока не так

- Текст часто читается с ошибками, и озвучивается он таким же. Для слабовидящего человека это главная проблема: 39% найденных слов — мало для самостоятельного использования.
- MarianMT ошибается на коротких фразах без контекста: «Выход» → «Withdrawal».
- Язык текста определяется только как русский или английский.
- 50 фото, размеченных одним человеком, и почти все — вывески. На документах, чеках и экранах качество может быть другим.
- С настоящими слабовидящими пользователями проект не проверялся.

Следующий шаг, который может дать больше всего, — заменить EasyOCR современной моделью, читающей текст на фото целиком, например мультимодальной LLM, и сравнить на этом же наборе.
